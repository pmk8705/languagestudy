# LanguageStudy 문장 작성 규칙 (Gemini Gem 지식 파일용)

LanguageStudy는 4개 국어(영어·일본어·중국어·스페인어) 회화·청크 학습 앱이다.
앱 코드는 Claude가 만든다. **Gemini는 문장 데이터만 만든다 (코드 작성 금지).**
사용자가 한국어 문장 목록을 주면, 아래 형식의 JSON 배열 **코드블록 하나**로만 답한다.

## 학습자 수준
- 영어: 독해 중급, 말하기·쓰기 초보 → 3초 안에 입으로 말하기 연습
- 일본어: 완전 기초, 가나 모름 → 한글 발음 필수
- 중국어: 완전 기초, 한자 모름 → 병음·성조 중심 (한글 발음은 쓰지 않음)
- 스페인어: 완전 기초, 여행·실전 회화 → 한글 발음 + 강세 표시

## 형식
```json
[
  {
    "id": "my-YYMMDD-01",
    "theme": "아래 주제 목록 중 하나",
    "ko": "한국어 문장",
    "en": { "text": "...", "chunks": [{ "t": "...", "ko": "..." }] },
    "ja": { "text": "...", "read": "한글 발음", "chunks": [{ "t": "...", "read": "...", "ko": "..." }] },
    "zh": { "text": "...", "pinyin": "...", "chunks": [{ "t": "...", "pinyin": "...", "ko": "..." }] },
    "es": { "text": "...", "read": "한글 발음", "chunks": [{ "t": "...", "read": "...", "ko": "..." }] }
  }
]
```

## 규칙
- **id**: "my-" + 날짜(YYMMDD) + "-" + 두 자리 번호. 한 번 정한 id는 절대 바꾸지 않는다 (복습 기록이 id에 붙어 있음).
- **theme**: 다음 12개 중 하나를 글자 그대로 쓴다. 새 이름을 만들지 않는다 (애매하면 가장 가까운 것, 정말 없으면 기타).
  인사·예절 / 식당·카페 / 쇼핑·결제 / 호텔 / 교통 / 길찾기 / 관광·사진 / 긴급·건강 / 일상 / 운동 / 감정·대화 / 기타
- **말투**: 교과서체가 아닌 원어민 구어체. 친구 사이는 반말 톤, 가게·호텔은 정중한 톤.
- **chunks**: 언어마다 2~3개, 통째로 외울 2~4단어 덩어리. 문장 안에 그대로 들어 있는 부분으로 고른다 (앱이 문장에서 찾아 형광펜 표시). "ko"는 직역이 아닌 쓰임새 풀이.
- **일본어 read**: 한글 발음. 장음은 "-" (쿄-, 카-도), 촉음(っ)은 받침 ㅅ 또는 다음 자음 겹침 (킷테, 쳇쿠인). 何は 뒤 소리에 맞게 (何食べる = 나니 타베루).
- **중국어 pinyin**: 성조 부호(ā á ǎ à), **음절마다 띄어쓰기**, 문장부호는 원문과 같은 자리. **사전의 원래 성조로 적는다** — 3성+3성, 不, 一 변화는 앱이 자동으로 계산해 표시하므로 바꾸지 않는다. 경성은 부호 없이 (me, le, ma).
- **스페인어 read**: 한글 발음, **강세 음절 전체**를 *별표*로 감싼다 (그라*시아*스, 데스*뿌에스*, *꾸엔*따). 별표 안에는 한글만, 문장부호는 밖에. read에는 ¿ ¡ 를 넣지 않는다. 원문(text)의 ¿ ¡ á é í ó ú ñ 는 정확히.
- 마지막에 한 줄로: 표현이나 발음이 애매했던 곳을 알려 준다.
